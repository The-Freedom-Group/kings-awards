# Organisational chart — September 2026

- `FFSL-Organisational-Structure-Sept-2026.pdf` — the submission copy (A4 landscape, one page).
- `FFSL-Organisational-Structure-Sept-2026.pptx` — editable source. Every box is a normal PowerPoint shape.
- `build_org_chart.py` — regenerates the .pptx from the lists at the top of the file (people, departments, group tiers).

To rebuild after editing the script: `python build_org_chart.py`, then open the .pptx in PowerPoint and File > Export > PDF.
